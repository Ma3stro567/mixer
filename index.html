Mixer

Локальные модели, которые пишут моды, рендер и миксины для Minecraft на Java под нужную версию игры. Mixer-0.5B использует настоящие классы Minecraft в — раза чаще, чем исходная Qwen, а её итог по моддингу — — против —.

Скоро

Как запустить

llama-server -m Mixer-0.5B-Q8_0.gguf -ngl 99 -c 8192 --jinja --temp 0.2 --repeat-penalty 1.1

Подходит llama.cpp с Vulkan (AMD и NVIDIA) или LM Studio. Чат откроется на 127.0.0.1:8080.

[MC=1.21.4][LOADER=fabric][MAP=yarn][JAVA=21]
Пиши код строго под эту цель. API других версий не используй.

Первая строка системного промпта — цель. MC — версия игры, LOADER — fabric, forge, neoforge или none, MAP — yarn, mojmap, mcp или official, JAVA — 8, 17 или 21.

Ум по ходу обучения

Каждая точка — промежуточная версия модели, проверенная теми же тестами. Полая точка на шаге 0 — исходная модель-основа до обучения, а не Mixer.
