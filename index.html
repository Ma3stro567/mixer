HumanEval-Java (MultiPL-E): одна попытка, жадная генерация, засчитывается только при прохождении всех тестов.

Mixer — эксперимент по дообучению маленьких языковых моделей (0.5–0.6B) для моддинга Minecraft на Java. Модели запускаются локально через llama.cpp. Цифры — из прогонов на 60 отложенных задачах по моддингу и 158 задачах HumanEval-Java; исходные таблицы лежат в папке data.
