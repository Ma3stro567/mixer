# Mixer Benchmarks

Результаты Mixer — маленьких моделей для моддинга Minecraft на Java.

- Сайт: открыть `index.html` или страницу GitHub Pages этого репозитория.
- Таблицы: папка `data/` (CSV).

Метрики автоматические, без ИИ-судьи: синтаксис Java, реальные импорты, утечки версий, якоря; HumanEval-Java (MultiPL-E) — проверка компиляцией и тестами.
