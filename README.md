# Mixer

Маленькая модель (0,5 млрд параметров), которая пишет моды, рендер и миксины для Minecraft на Java под конкретную версию, загрузчик и маппинги.

- Сайт: https://ma3stro567.github.io/mixer/
- Модель: `Mixer-0.5B-Q8_0.gguf` в Releases этого репозитория.
- Таблицы результатов: папка `data/` (CSV).

## Запуск

```
llama-server -m Mixer-0.5B-Q8_0.gguf -ngl 99 -c 8192 --jinja --temp 0.2 --repeat-penalty 1.1
```

Первая строка системного промпта — цель: `[MC=1.21.4][LOADER=fabric][MAP=yarn][JAVA=21]`.

Метрики автоматические, без ИИ-судьи: синтаксис Java, реальные импорты, утечки версий, якоря; HumanEval-Java (MultiPL-E) — проверка компиляцией и тестами.
